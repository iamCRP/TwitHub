# Twithub

Twithub is a **Flutter-based social media app** that combines the ease of micro-blogging with a central “hub” for users to connect, post short updates, and follow each other. 
Built with Firebase backend and Provider state-management, Twithub is fast, scalable, and optimized for a smooth social experience.

---

## 🚀 Features

- 🔗 **User Authentication**: Register, login, and manage your profile using email/password.  
- 📝 **Post Updates (“Twiths”)**: Share short text updates with other users.  
- 👥 **Follow System**: Follow other users to see their posts on your timeline.  
- ❤️ **Like Posts**: React to posts by liking them.  
- 💬 **Comments**: Engage with others by commenting on posts.
- 👤 **Profile Page**: View your posts, followers, and following.
- 🌙 **Dark / Light Mode**: Switch themes for better comfort anytime.
- 🚫 **Block Users**: Block unwanted users (they can’t view or interact).
- 🧭 **User Feed**: View a personalized feed based on people you follow.  
- 📊 **Realtime Data**: Powered by Firebase Firestore for instant updates.  
- 📱 **Responsive UI**: Clean and modern design, works well on different device sizes.  
- 🔄 **Pull to Refresh**: Refresh the feed easily for the latest posts.  
- 🔒 **Security**: Basic input validation and secure storage of user data.

---

## 🧑‍💻 Tech & System Features

- 🧠 State Management: Provider for efficient UI updates
- ⚡ Firebase Firestore for realtime data sync
- 🔐 Secure data using Firebase Authentication rules
- 🧱 Clean & Modular Codebase with reusable widgets
